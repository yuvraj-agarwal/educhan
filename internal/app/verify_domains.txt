# Academic domains educhan accepts for institutional verification.
#
# This file is embedded in the binary and is the default allowlist. Point
# EDUCHAN_VERIFY_DOMAINS at a file of your own to replace it entirely — the
# built-in list is not merged with it, so a deployment sees exactly the domains
# it configured.
#
# Blank lines and everything after a "#" are ignored. Two kinds of entry:
#
#   ac.in                     A domain suffix. Any address under it is accepted
#                             and the badge names the domain one level below the
#                             suffix, so ana@cse.nitk.ac.in earns [nitk.ac.in].
#
#   iitb.ac.in = IIT Bombay   An institution. The domain and every subdomain of
#                             it earn that badge instead, so ana@cse.iitb.ac.in
#                             earns [IIT Bombay]. Institution entries win over
#                             suffix entries however long each one is.
#
#   !nsw.edu.au               A denial. The domain and every subdomain of it
#                             are refused, whatever else matches. It is for
#                             school namespaces that sit inside an academic
#                             suffix.
#
# An address sitting directly on a suffix (someone@ac.in) is refused: a suffix
# is a namespace, not an institution.
#
# School addresses are refused on purpose, for child safety, and this is a
# limit on the badge, not on who may use the site. A badge that names a school
# marks its poster as a child at a place anyone can find; school mailboxes are
# often monitored by staff and closed when a pupil leaves; and many school
# systems forbid pupils using their address to sign up anywhere. So the aim is
# that every badge names a university or college. That is a goal, not a
# guarantee: no suffix maps exactly onto higher education. ac.uk, for one,
# admits further-education and sixth-form colleges, whose students can be 16,
# and a few US schools kept .edu domains registered before 2001.
# The badge is also 18+ by attestation (build plan 2.14), whatever the domain.
#
# Reviewing a suffix: a namespace only belongs here when it is reserved for
# higher education. Where a country puts schools under the same suffix as its
# universities, either deny the school namespaces below or drop the suffix and
# list the universities as institutions instead. Every suffix is marked:
# "reviewed" means it was checked this way, "not checked yet" means it was not
# and may still admit schools. Prefer named institutions to an unchecked
# suffix.
#
# The site does not target the EU for now, so no EU member-state suffixes are
# listed. If that changes, add EU universities by name rather than by suffix:
# edu.it, for one, also holds Italian secondary schools (liceo.edu.it).
